# 🔐 Módulo de Autenticación (Auth)

**¿Para qué sirve esta carpeta?**
Aquí va TODO el código relacionado con el inicio de sesión, registro y recuperación de contraseñas de los usuarios.

**¿Qué archivos debes poner aquí?**

- `components/`: Formularios de login y registro, botones de Google/GitHub.
- `hooks/`: Funciones para iniciar o cerrar sesión (ej. `useAuth`).
- `utils/`: Validaciones de correos y contraseñas.

**🛑 Regla de Oro:**
Solo temas de acceso. Si el usuario ya entró y está editando su nombre o foto, eso pertenece a la carpeta `profile` (Perfil), no aquí.
