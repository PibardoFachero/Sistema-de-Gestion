# 📅 Módulo de Calendario (Calendar)

**¿Para qué sirve esta carpeta?**
Aquí va la vista de agenda o calendario, para que los usuarios puedan ver en qué fechas caen sus entregas, proyectos o sesiones de estudio.

**¿Qué archivos debes poner aquí?**
- `components/`: La grilla del mes/semana, eventos en el calendario.
- `utils/`: Funciones para manejar fechas, calcular semanas, etc.

**🛑 Regla de Oro:** 
El calendario *muestra* las tareas, pero la lógica de cómo se estructura una tarea sigue perteneciendo a `tasks`.
