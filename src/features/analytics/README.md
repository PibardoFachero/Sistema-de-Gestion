# 📊 Módulo de Analítica y Gráficos (Analytics)

**¿Para qué sirve esta carpeta?**
Este es el espacio para la Visualización de Datos. Aquí construiremos el Dashboard, los gráficos de pastel/barras de progreso, informes de tiempo invertido y el Diagrama de Gantt.

**¿Qué archivos debes poner aquí?**
- `components/`: Gráficos visuales usando librerías (como Recharts o Tremor), tablas de resumen.
- `utils/`: Cálculos matemáticos o formateo de datos para que los gráficos los entiendan.

**🛑 Regla de Oro:** 
Esta carpeta "lee" información de Proyectos y Tareas, pero no debería ser responsable de *crear* tareas nuevas. Es un módulo principalmente de vista y reportes.
